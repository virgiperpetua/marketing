Churn Sheet

Production tooling built from a real workplace problem.

REAL WORKPLACE PROJECT

A single screen for flavour status, stock visibility, and production timing.

Built for day-to-day use on the store floor, with a simple, glanceable interface rather than a report-heavy workflow.

Real workplace project Self-initiated In production use Full-stack
The problem

I manage day-to-day operations at Gelato Messina and kept running into the same friction: checking flavour status, stock consumption, and production timing meant walking the floor or pulling out a phone in the middle of a shift.

What I built

I built Churn Sheet, a software tool designed around that workflow. It brings flavour status, stock visibility, and production timing into one place so the store can make faster day-to-day decisions without breaking flow.

My role

I identified the operational problem, shaped the workflow, built the software, and tested it in the same environment it was designed for.

Technology

Next.js 14, React 18, Tailwind CSS, Zod, and a localStorage data layer behind a repository interface ready for a future API.

Outcome

Built around a real operational workflow and designed for day-to-day use in a live store environment.
